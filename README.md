# ⚔️ Elves Online (Açık Beta)

Kadim Krallıklar MMORPG Web Oyunu.

- **Oyun Adı:** Elves Online
- **Yapımcı:** Emirhan Kalaycı
- **Yapım Şirketi:** Han Gaming Studio
- **Oyun Durumu:** Açık (Beta)
- **Canlı Demo (Web / Mobil):** [https://elves-online.vercel.app](https://elves-online.vercel.app)

---

## 🌟 Oyun Özellikleri
- 🏹 **Klasik MMORPG Stat Dağıtımı:** Can (HP), Güç (STR), Çeviklik (AGI), Zeka (INT) - Seviye başına +6 Stat Puanı, Metin2 tipi 90 Cap tavan sınırı.
- 🏰 **3 Kadim Krallık:** Aeltherin (Kadim Orman), Vaeloria (Güneş Tapınağı), Sylvandra (Gece Muhafızları).
- ⚔️ **3 Sınıf Uzmanlığı:** Savaşçı, Gölge Suikastçısı (Ninja), Arcane Büyücüsü.
- 💀 **Sürekli Zindan Avı & Boss Arenası:** Otomatik iksir tüketimi, 24 saatte Seviye 30 kalibrasyonlu hardcore seviye eğrisi, %3 adil eşya düşme oranı.
- ⚡ **Bulut Altyapısı:** Frankfurt (`eu-central-1`) Supabase veritabanı ve Vercel Global Edge dağıtımı.

---

## 🛠️ Teknolojiler
- **Frontend:** React 19, Vite, Tailwind CSS, Lucide React
- **Veritabanı:** Supabase (PostgreSQL Altyapısı)
- **Dağıtım (Hosting):** Vercel Edge Network
